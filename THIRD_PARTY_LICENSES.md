# Third-party licenses

annotation-helper's executables include code from the projects below. Their licenses
require these notices to be passed on with copies of the executables.

| Component | Used for | License |
|---|---|---|
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 1.8.3, including ggml | speech recognition | MIT |
| [miniaudio](https://miniaud.io) (bundled with whisper.cpp) | microphone recording, WAV reading | public domain (Unlicense) or MIT No Attribution |
| [stb](https://github.com/nothings/stb) (stb_image, stb_image_write, stb_image_resize2, stb_truetype) | PNG files and banner text (Linux) | MIT or public domain |
| [zigwin32](https://github.com/marlersoft/zigwin32) | Windows API declarations | MIT |
| [Zig](https://ziglang.org) standard library and runtime | the program itself | MIT |

The whisper speech model (`ggml-*.bin`) is not part of the executables; it is downloaded
separately. The model weights were published by OpenAI under the MIT license.

The executables also contain parts of the C/C++ runtime Zig builds them with (LLVM libc++,
libunwind and compiler-rt, under the Apache License 2.0 with LLVM Exceptions, which requires
no notice for compiled code; on Windows also the MinGW-w64 runtime, largely public domain).
